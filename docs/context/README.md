# Contexto aportado por ti

Deja aquí **cualquier material que el agente deba tener en cuenta** y que no nació en este repo: una spec de otra conversación, un `.md` de requisitos, un PDF del cliente, un contrato, capturas, exportaciones de un chat, un datasheet.

- Formatos libres (`.md`, `.pdf`, imágenes, `.txt`, `.csv`…). Si puedes, nombra los archivos con sentido: `2026-10-spec-previa-alarmas.md`.
- Es **tuyo**: el agente lo lee, **no lo edita ni lo reorganiza** (si algo debe volverse spec, lo convierte con `/tc-spec` y deja el original aquí).
- Se consulta al hacer `/tc-prime` y `/tc-spec`: el agente lista esta carpeta y lee solo lo relevante para la tarea (no la carga entera). Si un archivo es largo, añade arriba un párrafo de resumen: ahorra tokens.
- No metas secretos ni datos de producción; la carpeta se versiona con el repo.
